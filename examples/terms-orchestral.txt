# 語彙注入ファイル（両エンジン共通）
#
#   audio-transcribe    --terms  → faster-whisper の hotwords
#   audio-transcribe-dg --terms  → Deepgram Nova-3 の Keyterm Prompting
#
# 書式: 1行1語、# 以降はコメント、空行は無視。重み指定は書かない。
# 効くのは「一般語彙から外れていて、かつ誤ると記録が壊れる語」。
# 一般的な日本語（「もう一度」等）を入れても効果はない。
#
# Deepgram は 1 リクエストあたり全 keyterm 合計 500 トークンが上限。
# 日本語は 1 語で複数トークンになるため、100 語程度を目安に絞る。
#
# テイクごとに固有名詞（曲名・団体名・指揮者名・奏者名）を足して使う。
# 固有名詞は公開物に載せない運用なら、このファイルは配布対象から外すこと。
