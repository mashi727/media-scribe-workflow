# WORKLOG transcription — 2026-08-14

## 11:20 — 記法を変えて下流を壊した。呼び出し側を触らない方式へ作り直す

<!-- model: Claude Opus 5 (1M context), cwd: media-scribe-workflow, duration: 約3時間 -->

### TL;DR

`tex-link-timestamps` が本文の `\ts{HH:MM:SS}` を `\tsy{HH:MM:SS}{秒}` へ書き換えていたのが、
**団員ダッシュボードの `build_leok.py` を壊していた**。同ツールは `\ts{}` を特別扱いして
`data-sec` 属性を出しており、それがページ内 YouTube 再生のフックだった。
つまり **YouTube 導線は元から存在しており、私はそれを重複実装したうえで上流の記法を壊した。**

**`build_events.py` を壊したのと同じ誤りを、同じ月に2度繰り返している。**
呼び出し側は据え置き、プリアンブルの定義だけを差し替える方式に改めた。1 commit（`fec0e2c`）。

### 何が起きていたか（実測）

`build_leok.py` の `inline()` に同じ文を通した結果:

```
\ts{00:47:07}         -> <span class="leok-ts" data-sec="2827">[00:47:07]</span>
\tsy{00:47:07}{2827}  -> 00:47:0771小節 2827 を返す
```

`\tsy` は未知コマンドなので、(1) `data-sec` が消えて再生フックが死ぬ、(2) 秒数が本文に漏れる、
(3) `flush()` の順序の都合で**出力位置が前へずれる**。未知コマンドの既定動作が
「名前を捨てて最初の `{...}` の中身を残す」なので、2つ目の引数が裸のテキストとして残る。

被害が `00_Horn_Works` 側のコピーに留まっていたのは偶然で、`resources/` 側は 8/1 版のままだった。
**これを気づかずに同期していたら、公開中のダッシュボードのタイムスタンプが全滅していた。**

### 直し方の型

**界面（呼び出し側の記法）は動かさない。実装（定義）だけを差し替える。**

```latex
\newcommand{\videoid}{25MxIZQ8JLU}
\expandafter\def\csname ts@s@00:47:07\endcsname{2827}   % 秒は生成時に確定
...
\newcommand{\ts}[1]{\href{https://youtu.be/\videoid?t=\csname ts@s@#1\endcsname}{...}}
```

`build_leok.py` は `\begin{document}` 以降しか読まないので、プリアンブルの変更は下流から不可視。
これで PDF 単体でもリンクが効き、ダッシュボードの解析は無傷になる。

時刻→秒は **Python で確定させて `\csname` の対応表にする**。LaTeX 側で文字列を parse すると
hyperref の URL 処理で catcode が変わり、区切り引数のマッチが壊れうるため。
`\directlua` / `\numexpr` も検討したが、同じ理由で採らなかった。

`--unlink` を足した。旧版が書き換えた `\tsy` 呼び出しと、旧版が無標で挿入したブロックも巻き戻せる。
**以後の挿入は `% >>> tex-link-timestamps >>>` のマーカーで囲む**（無標だと機械的に除去できない）。

### ハマった点・エラーと回避策

- **`re.sub` の置換文字列に `\s` を含む LaTeX を渡して `bad escape \s`。** 置換側は lambda で返す。
- **旧版がミリ秒を落としていた。** `\ts{3:12:02.170}` → `\tsy{3:12:02}{11522}`。`--unlink` では戻らない。
  過去分は `.prelink` から復元した（7/26 の20箇所・7/05 の3箇所が復活）。8/9 は元からミリ秒無しで無傷。
- **旧版の挿入ブロックが無標**だったので `--unlink` で取り残し、`\videoid` の二重定義になるところだった。
  レガシー用の正規表現を追加して除去。
- **`\ts{01:48}` / `\ts{03:12}` は時刻ではなく演奏の長さだった**（7/26 統合記録）。`\ts` は動画位置を表す
  マクロなので誤用。素のテキストに修正。**旧版が3要素の時刻しか書き換えなかったおかげで発見できた**
  ——素通ししたものが可視化されるという、意図しない検査効果。
- **`data-sec` が 0 件だと誤報告した。** JSON のエスケープ（`data-sec=\"...\"`）を正規表現が見落としていた。
  実際は 420/420。**生成物を測るときはエスケープ後の形で測る。**
- サンドボックスが作業ディレクトリ外への書き込みを止める。Desktop / 00_Horn_Works / differance-lab は
  `dangerouslyDisableSandbox` が必要だった。

### 学習事項（次に効くもの）

**成果物の記法を変える前に、その成果物を他に誰が解析しているかを確かめる。**
`.tex` は「PDF の材料」ではなく**複数の消費者を持つ構造化データ**だった。
`build_events.py`（ダッシュボードの元ネタ）と `build_leok.py`（団員ダッシュボード）の2つが読んでいる。

どちらの事故も、ユーザーの何気ない確認で発覚している。
1度目は「これを行うとダッシュボードの元ネタになるんでしたっけ」、
2度目は今回の作業場所の確認。**私の側からは一度も気づけていない。**

直し方の型は毎回同じ:**呼び出し側（界面）は据え置き、定義・実装側だけを差し替える。**
今回はプリアンブルが下流から不可視という性質が使えたので、界面を完全に固定できた。
