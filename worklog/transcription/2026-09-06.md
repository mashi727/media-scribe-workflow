### 調べて分かった外部仕様
- **`build_events.py` の R イベント抽出正規表現**（`~/.claude/skills/rehearsal/scripts/build_events.py:175-176`）:
  `\\subsection\{((?:R\d\d|L\d|T\d))｜(.*?)\\tsy?\{time\}...\}` に続けて次行 `\\label\{ev:\1\}`。
  → **R/L/T は必ず `\subsection` レベル**・見出し末尾に `\ts{時刻}`・直後行に `\label{ev:…}`。`\subsubsection*` だと拾われない。演奏長は `[演奏]` 欄の `[H:MM:SS]`/「約N秒」「計N分N秒」から集計。
- **`tex-link-timestamps` は本文中の全 `\ts{}` を時刻として parse**する。説明用に `\ts{HH:MM:SS}` のような非時刻を書くと `error: 時刻として解釈できない \ts{} があります: HH:MM:SS` で停止。説明例は `\texttt{[HH:MM:SS]}` 等にする。適用後は `\ts` 定義が `\href{https://youtu.be/\videoid?t=\csname ts@s@#1\endcsname}{...}` になり、時刻→秒は `\csname ts@s@…\endcsname` の対応表で確定（LaTeX で parse しない）。
- **differance-lab の複数公演運用は確立済み**（`scripts/build_leok_all.py` の `EDITIONS`）。id `14`(第14回・active・use_common) と `jozenji26`(定禅寺・active=False・`pieces_in_program`)。1合奏の記録 .tex は**両エディションの `resources/情報まとめ/{第14回,定禅寺}/` に同一ファイルを置く**（gitignore）。命名は `YYYYMMDD_合同練習_統合記録.{tex,pdf}`（「レオケ」を付けない既存慣習に合わせる）。公開は `git add scripts/ wp-content/.../leok-private/` を commit→push（=Deploy Theme to CoreServer 起動）。push 前に `git fetch && git rebase origin/main`（missponne の自動コミット先行対策）。
