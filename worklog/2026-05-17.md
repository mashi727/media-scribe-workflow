### 重要な決定と理由

- **分割粒度は 3 リポジトリ（CLI / GUI / Report）＋ アーカイブ**
  - 理由: Udemy コース 2〜3 本構成（ユーザー回答）に対応。GUI はバイナリリリース CI/CD が独立サイクル、CLI は依存薄で入門教材最適、Report は AI 統合の応用編。コース単位＝リポジトリ単位で受講生が章ごとに clone できる
- **VCE 形式は Report 側に集約**
  - 理由: ユーザー回答「レポート生成の一部」。実調査で `core/` は production code 未参照（テストのみ）と判明し、Report 側に置いても GUI に影響しないと確認
- **アーカイブはローカル退避（git 外指定）＋ Dropbox 内兄弟位置 ＋ git 初期化**
  - 理由: ユーザー回答。Dropbox 内なら既存バックアップ運用と整合、git 初期化で追加・削除を追跡可能
- **未コミット GUI 変更は 1 コミットに集約（2 機能併記）**
  - 理由: `main_workspace.py` が両機能にまたがり、厳密分離するには interactive add が必要で手間に対するリターンが薄い。コミットメッセージ本文で 2 機能を箇条書き列挙する形で妥協
- **元リポジトリの GUI 削除は本日見送り**
  - 理由: video-chapter-editor の実動作検証（pytest 実行、GUI 起動、PyInstaller ビルド）が未実施。検証通過まで元を残すことでロールバック可能性を確保
- **filter-repo で `tests/` を丸ごと残し、後で個別削除**
  - 理由: filter-repo の `--invert-paths` 2 段階よりも、抽出後の通常コミットで非該当テストを削除する方がシンプルで追跡しやすい
- **`pipeline/__init__.py` は srt_parser のみ export に書き換え**
  - 理由: `report_generator` が GUI 側に存在しないため、`from .report_generator import ...` で ImportError が発生。GUI repo に閉じた状態で `import media_scribe_workflow.ui.app` を成立させるために必要

### ハマった点・エラーと回避策

- **現象（filter-repo の最初の実行）**：
  ```
  Aborting: Refusing to destructively overwrite repo history since
  this does not look like a fresh clone.
    (expected freshly packed repo)
  Note: when cloning local repositories, you need to pass
        --no-local to git clone to avoid this issue.
  Please operate on a fresh clone instead.  If you want to proceed
  anyway, use --force.
  ```
- **原因**：ローカルパスからの `git clone` はデフォルトで hardlink 経由となり、filter-repo が "freshly packed repo" と認識しない
- **解決**：一度 `/tmp/vce-extract-work` を削除し、`git clone --no-local /Users/.../media-scribe-workflow /tmp/vce-extract-work` で再クローン → filter-repo 成功

- **現象（GUI 抽出後の import 検証）**：
  ```
  pipeline.srt_parser import FAILED: ModuleNotFoundError: No module named 'media_scribe_workflow.pipeline.report_generator'
  ui.workers.base import FAILED: ModuleNotFoundError: No module named 'media_scribe_workflow.pipeline.report_generator'
  ui.app import FAILED: ModuleNotFoundError: No module named 'media_scribe_workflow.pipeline.report_generator'
  ```
- **原因**：`pipeline/__init__.py` が `from .report_generator import ReportGenerator, ReportMetadata` を実行するが、GUI 抽出時に `report_generator.py` を含めていない
- **解決**：`pipeline/__init__.py` を「srt_parser のみ export」に書き換えて commit `5abee56`
